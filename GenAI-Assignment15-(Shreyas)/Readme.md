# 🤖 Assignment 15: Core ML Algorithms, Metrics & Model Behavior

A practical Machine Learning assignment covering fundamental algorithms, evaluation metrics, and model behavior using Python and Scikit-learn.

## 📌 Topics Covered

### 📈 Regression
• Linear Regression  
• MAE, MSE and RMSE  
• Actual vs Predicted visualization

### 🧠 Classification
• Logistic Regression  
• Gaussian Naive Bayes  
• K-Nearest Neighbors (KNN)  
• Accuracy, Precision, Recall and F1-score  
• Confusion Matrix and Classification Report

### 📊 Model Behavior
• Overfitting and Underfitting  
• Bias and Variance  
• Training vs Testing Accuracy

## 🛠️ Technologies

Python • Pandas • NumPy • Matplotlib • Scikit-learn

❤️ **Heart Disease Dataset**

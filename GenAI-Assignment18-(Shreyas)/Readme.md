# 🧠 Assignment 18: Text Vectorization & TF-IDF

A practical Natural Language Processing assignment covering One-Hot Encoding, Bag of Words, N-grams, TF-IDF, and vectorizer parameter exploration using a cleaned IMDB movie review dataset.

## 📌 Dataset

**IMDB Dataset of 50K Movie Reviews**

This assignment uses a **cleaned and preprocessed version** of the IMDB movie reviews dataset.

🔗 [Original Dataset - Kaggle](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)

## 📚 Topics Covered

### 🔢 One-Hot Encoding
- Manual One-Hot Encoding
- Vocabulary creation
- One-Hot Encoding using `CountVectorizer`
- Binary word representation

### 👜 Bag of Words (BoW)
- Bag of Words representation
- Vocabulary size
- Feature vectors
- Word frequency analysis
- Top and least frequent words

### 🔗 N-Grams
- Unigrams
- Bigrams
- Trigrams
- Combined Unigrams + Bigrams
- Effect of N-grams on vocabulary size and dimensionality

### 📊 TF-IDF
- TF-IDF vectorization
- TF-IDF matrix
- High TF-IDF words
- Low TF-IDF words
- Comparison between BoW and TF-IDF
- Down-weighting common words

### ⚙️ Vectorizer Parameters
- `max_features`
- `min_df`
- `max_df`
- Effect of parameters on vocabulary size
